Пользовательское соглашение сервиса «Мои ложки»

Настоящее соглашение определяет порядок использования сервиса «Мои ложки», правила работы с аккаунтом и общие условия взаимодействия пользователя с проектом.

1. Общие положения

Используя сайт и приложение «Мои ложки», пользователь подтверждает, что ознакомился с настоящим соглашением и принимает его условия.

2. Назначение сервиса

Сервис предназначен для личного использования: планирования задач, хранения пользовательских записей, настройки личного пространства и сопровождения повседневной активности.

3. Аккаунт пользователя

  • Пользователь самостоятельно отвечает за сохранность данных для входа.
  • Пользователь обязуется указывать достоверный email для работы аккаунта и восстановления доступа.
  • Пользователь вправе прекратить использование сервиса и запросить удаление данных через контактный email.

4. Допустимое использование

  • Нельзя использовать сервис для незаконной деятельности.
  • Нельзя пытаться нарушить работу сайта, получить несанкционированный доступ к данным или обходить технические ограничения.
  • Нельзя выдавать себя за другое лицо при использовании аккаунта.

5. Добровольная поддержка проекта

Пользователь вправе добровольно поддержать проект разовым платежом. Условия такой поддержки, порядок оплаты и возврата средств описаны в отдельной публичной оферте.

6. Персональные данные

Порядок обработки персональных данных определяется отдельной политикой обработки персональных данных, размещённой на сайте.

7. Ограничение ответственности

Сервис предоставляется по модели «как есть». Исполнитель принимает разумные меры для стабильной работы проекта, но не гарантирует абсолютную бесперебойность сервиса или отсутствие технических сбоев.

8. Изменение условий

Исполнитель вправе обновлять настоящее соглашение при развитии сервиса, изменении функциональности или требований законодательства. Актуальная версия публикуется на сайте.

9. Контакты

По вопросам использования сервиса можно обратиться по адресу: moilozhkiproject@yandex.ru.
